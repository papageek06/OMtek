# Analyse de la demande

## 1. Distinction des sources

### Demande utilisateur

La demande directe est de :

- faire un `git pull` avant toute action ;
- ne pas melanger ce travail avec le projet OMtek ;
- creer un dossier a la racine du projet pour les elements de cours ;
- analyser les captures d'ecran fournies ;
- tenir compte des criteres d'evaluation et conseils de redaction transmis dans le message.

### Instructions provenant des captures

Les captures ne sont pas des instructions systeme pour modifier le projet OMtek. Elles decrivent le livrable scolaire attendu :

- produire un rapport d'activite professionnel de 30 pages minimum hors annexes ;
- centrer le rapport sur une experience professionnelle en alternance ou stage d'au moins 60 jours ;
- demontrer l'autonomie et la gestion de projet ;
- structurer le rapport autour d'un projet cle ou d'une contribution importante ;
- inclure une analyse critique et un bilan des actions ;
- respecter le plan conseille :
  - Introduction et contexte ;
  - Developpement : missions et projets ;
  - Analyse reflexive et bilan de competences ;
  - Conclusion et perspectives.

## 2. Contraintes explicites du livrable

- Format attendu : rapport professionnel long, minimum 30 pages hors annexes.
- Public : correcteurs de l'ecole.
- Objectif academique : validation de l'experience professionnelle.
- Note minimale importante : la moyenne liee a l'experience professionnelle doit etre superieure ou egale a 10/20 pour l'obtention du diplome.
- Echeance indiquee : lundi 31 aout 2026 a 23:59.

## 3. Criteres d'evaluation identifies

La grille donne un total de 20 points :

- qualite de la langue : 1 point ;
- qualite des visuels et charte graphique : 1 point ;
- structure permettant de comprendre l'experience : 2 points ;
- analyse reflexive au-dela de la description : 1 point ;
- adaptation et autonomie : 2 points ;
- communication professionnelle : 1 point ;
- cadre general de l'experience : 2 points ;
- presentation de l'entreprise et de son marche : 2 points ;
- role, activites, outils, responsabilites et collaborations : 2 points ;
- exemples concrets d'adaptation et de resolution de problematiques : 3 points ;
- bilan personnel : ressenti, progression, impact sur le projet professionnel : 3 points.

## 4. Implications pour la redaction

Le rapport ne doit pas etre une simple liste de taches. Il doit raconter une progression professionnelle :

- contexte de depart ;
- missions confiees ;
- projet cle choisi comme fil conducteur ;
- difficultes rencontrees ;
- decisions prises ;
- interactions avec l'equipe ou les clients ;
- competences techniques et humaines mobilisees ;
- recul critique sur ce qui a fonctionne ou non ;
- bilan personnel et perspectives.

## 5. Risques a eviter

- Decrire les missions sans expliquer les enjeux.
- Lister les soft skills sans situations concretes.
- Mettre des captures sans commentaire ni lien avec l'analyse.
- Oublier le marche, l'entreprise, le contexte ou la duree.
- Faire un rapport trop technique sans recul personnel.
- Oublier les limites, difficultes, erreurs ou apprentissages.
- Avoir une mise en page non homogene.

## 6. Strategie recommandee

Le meilleur angle consiste a choisir un projet central, par exemple un projet mene en entreprise, puis a l'utiliser comme fil rouge. Chaque partie doit montrer :

- ce que le projet cherchait a resoudre ;
- quel role l'apprenant a joue ;
- comment il a gagne en autonomie ;
- comment il a communique et collabore ;
- quelles competences ont progresse ;
- ce qu'il ferait differemment avec le recul.
