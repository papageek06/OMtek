# Checklist d'evaluation

Cette checklist sert a verifier le rapport avant rendu.

## Forme du livrable

- [ ] Le rapport contient au moins 30 pages hors annexes.
- [ ] Le vocabulaire, la syntaxe et la grammaire ont ete relus.
- [ ] La mise en page est homogene.
- [ ] Les titres et sous-titres suivent une hierarchie claire.
- [ ] Les visuels sont nets, lisibles et utiles.
- [ ] Les visuels sont commentes dans le texte.
- [ ] Les captures sensibles sont anonymisees.
- [ ] La charte graphique est sobre et uniforme.

## Structure et analyse critique

- [ ] Le rapport suit le plan attendu : introduction, developpement, analyse reflexive, conclusion.
- [ ] Le lecteur comprend clairement l'experience professionnelle vecue.
- [ ] Le rapport ne se limite pas a decrire des taches.
- [ ] Chaque mission importante explique le contexte, l'objectif, l'action et le resultat.
- [ ] Une analyse critique est presente : limites, difficultes, apprentissages.

## Autonomie et adaptation

- [ ] Une ou plusieurs situations montrent l'autonomie.
- [ ] Une ou plusieurs situations montrent l'adaptation a une contrainte.
- [ ] Les decisions prises sont expliquees.
- [ ] Les arbitrages ou priorites sont justifies.
- [ ] Les problemes rencontres et les solutions apportees sont decrits concretement.

## Communication professionnelle

- [ ] Les interactions avec l'equipe sont documentees.
- [ ] Les echanges avec le tuteur, les clients ou d'autres services sont expliques.
- [ ] Le rapport montre comment les feedbacks ont ete pris en compte.
- [ ] Les supports de communication eventuels sont cites : reunion, ticket, mail, compte rendu, documentation.

## Cadre general de l'experience

- [ ] Le nom de l'entreprise est present.
- [ ] La localisation est indiquee.
- [ ] Le secteur d'activite est explique.
- [ ] La duree et les dates de l'experience sont indiquees.
- [ ] Le service ou l'equipe d'accueil est presente.
- [ ] Le marche de l'entreprise est presente.
- [ ] Les enjeux de l'entreprise sont relies aux missions.

## Competences mises en oeuvre

- [ ] Le role de l'apprenant est clair.
- [ ] Les activites et taches sont comprehensibles.
- [ ] Les outils utilises sont presentes.
- [ ] Les responsabilites sont explicites.
- [ ] Les collaborations sont identifiees.
- [ ] Des exemples concrets d'adaptation sont presentes.
- [ ] Des exemples concrets de resolution de probleme sont presents.

## Bilan personnel

- [ ] Le ressenti personnel est exprime avec recul.
- [ ] La progression professionnelle est expliquee.
- [ ] Les competences acquises sont reliees a des situations.
- [ ] Les axes d'amelioration sont identifies.
- [ ] L'impact sur le projet professionnel est explique.
- [ ] La conclusion ouvre sur des perspectives realistes.
